PATEL TOURS & TRAVELS — MULTIPAGE WEBSITE

Open index.html in a browser to preview the site locally.

Pages included:
- index.html — Home / trip overview
- itinerary.html — Full route overview
- day-1.html through day-5.html — Individual daily itinerary pages
- planning.html — Overnight plan and interactive checklist

Keep styles.css and the assets folder alongside the HTML files. The site is responsive and uses the destination photos extracted from the supplied PDF. Web fonts load from Google Fonts when internet access is available; system fallbacks are included.

The content preserves the proposed itinerary and its caveats: times are estimates, bookings are not included, and holiday opening hours, tickets, weather, road conditions and access should be confirmed.
